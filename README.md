<h1>Инструкция администратора для бота заявок</h1>
<ol>
    <li>Зайти на сайт https://north-tribune.ru</li>
    <li>Просмотреть заявку и аккаунт кандидата с помощью ссылки на Telegram (заявки отображены в порядке их подачи - сначала самая старая из нерассмотренных)</li>
    <li>
        Принять решение:
        <ol>
            <li>Нажать кнопку "Одобрить", если все в порядке - кандидату придет ссылка на бота подписки</li>
            <li>Нажать кнопку "Отклонить", если что-то не так - кандидату придет сообщение о том, что его заявка отклонена</li>
        </ol>
    </li>
</ol>
